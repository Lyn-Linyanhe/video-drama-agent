# 音频台词与字幕修复设计

## 目标

修复成片中角色对话缺失的问题，并在分镜制作工作台提供可持久化的字幕开关。字幕默认开启。修复范围覆盖音频生成、视频合成、FFmpeg 回退和前端状态反馈，不改变剧本、角色、场景或视频生成流程。

## 已确认问题

1. `AudioAgent` 会为每一句台词生成音频，但 `SceneAudio.tts_audio_path` 只有一个字段；循环保存时后生成的路径覆盖之前的路径，因此一个镜头通常只保留最后一句台词。
2. Edge-TTS 导入、网络或生成失败时，当前逻辑生成静音文件并返回成功路径，前端无法区分真实配音和静音占位。
3. MoviePy 合成异常后会回退到只拼接视频的 FFmpeg 路径，该路径不处理 TTS、BGM 或字幕，却仍可能返回成功成片。
4. 字幕当前被无条件烧录，项目状态和工作台没有字幕配置。

## 方案

### 音频数据模型

新增逐句 `DialogueAudio` 数据，保存 `scene_id`、台词序号、角色名、台词文本、语音 ID、生成文件路径、实际时长和错误信息。`SceneAudio` 持有按剧本顺序排列的逐句音频列表。

保留 `tts_audio_path` 和 `tts_text` 作为旧项目兼容字段。读取旧状态时，若没有逐句列表且有旧路径，则将该路径当作一个兼容音轨，不丢弃既有项目资产。

### 生成与错误处理

`AudioAgent` 对每句台词分别生成 TTS，并只把实际存在、可读取的音频标为成功。失败结果记录到对应逐句音频和执行日志，接口响应同时返回每个镜头的成功数、失败数和失败原因。

不再把静音占位文件伪装为配音成功。若当前环境无法使用 TTS，用户将在工作台直接看到失败原因，而不会得到无声但显示成功的结果。

### 镜头混音与时长

合成 Agent 读取同一镜头的全部逐句音轨，按照剧本顺序连续排列，并与原视频音频混合。BGM 始终作为低音量背景，在台词段落中继续降音量。

优先使所有台词在镜头内完整播放：当逐句音频总时长超过视频镜头时长时，先将语音压缩至合理上限；仍无法容纳时，冻结镜头最后一帧并延长镜头，避免截断角色台词。实际延长信息写入日志。字幕时长与最终镜头时长保持一致。

MoviePy 是主合成路径。FFmpeg 回退路径同样接收逐句音轨、BGM 和字幕设置；若两条路径均失败，接口返回错误而不是写入无声的伪成功成片。

### 字幕配置与工作台

在 `DramaState` 增加项目级 `subtitle_enabled`，默认 `True`，序列化、恢复旧项目时均安全兼容。分镜制作工作台的“合成作品”操作旁显示字幕开关，修改后立即保存到服务端项目状态。

字幕开启时，按镜头的角色名和台词烧录字幕；关闭时，成片不叠加字幕。音频生成和合成状态区显示配音成功数、失败数与可操作的错误原因。

## 接口与兼容性

为分镜制作项目级工作流增加或扩展一个保存输出设置的接口，并让 `/production/assemble` 从服务端持久化的状态读取 `subtitle_enabled`。旧 `/api/audio`、`/api/assemble` 路径保留兼容，默认按开启字幕处理。

现有 `AudioAssets`、历史音频文件、项目状态和视频资产均不迁移、不删除。旧项目会通过兼容字段继续合成，新的音频生成开始使用逐句音轨。

## 验收与测试

1. 一个镜头含多名角色、多句台词时，成片按剧本顺序播放每一句，且角色不会被后一句覆盖。
2. 单句 TTS 失败时，工作台显示角色和失败原因；不会把静音文件报告为生成成功。
3. 字幕默认开启；关闭后刷新、重新进入项目和合成成片均不出现烧录字幕。
4. 逐句总时长超过视频镜头时，最终成片保留完整台词，并记录时长调整。
5. MoviePy 不可用或主路径失败时，FFmpeg 回退仍保留台词、BGM 和字幕开关效果；两者都失败时接口返回明确错误。
6. 旧项目状态、旧 `tts_audio_path` 和既有视频能正常读取，不删除既有资产。
