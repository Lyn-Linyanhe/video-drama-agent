# Seedance 原生对白与字幕校正设计

## 目标

Seedance 新视频任务默认开启供应商原生音频，由视频模型生成角色对白和现场声音；项目后期只负责加入 BGM、项目音效、字幕和响度处理。其他视频供应商继续使用现有外部 TTS 流程。原生音频生成后，系统可选使用本地 ASR 对齐字幕；ASR 不可用时回退到剧本字幕时间轴，不阻断内部试片。

## 范围与约束

- Seedance 原生音频只对能力表明确支持 `generate_audio` 的模型开启，供应商不支持时任务明确降级或失败，不静默假装成功。
- 原始结构化剧本对白保持不变。Seedance 请求可携带镜头级对白块，但不改写剧本数据。
- BGM 始终由后期混音负责，跨镜头使用统一时间轴，镜头边界采用现有淡入淡出/交叉淡化规则。
- 外部 TTS 保留为非 Seedance 默认路径和原生音频失败时的可配置回退路径。
- ASR 使用可选本地 `faster-whisper` 适配器，不强制下载模型；未安装、模型不可用或置信度不足时保留剧本字幕并显示校正未完成。
- 不引入云端 ASR、声音克隆或口型二次合成。

## 数据流

```text
结构化剧本 + 最终镜头提示词
    -> 镜头对白计划（原始对白引用、说话人、对白块、时长预算）
    -> Seedance generate_audio=true
    -> 下载带原声视频并记录 native 音频来源
    -> 提取音频流
    -> 可选 ASR：识别片段、时间戳、置信度、与剧本对白匹配
    -> 字幕时间轴（校正结果或剧本回退）
    -> FFmpeg：视频原声 + BGM + 音效 + 字幕 + 响度规范化
```

## 后端设计

### Seedance 客户端

- `generate_video()` 增加显式 `generate_audio` 参数；Seedance 原生音频策略默认传 `true`。
- 在 Seedance 的最终 provider prompt 中加入结构化 `【对白】` 块，包含说话人、表达方式和自动适配后的短对白。
- 轮询完成后保留带音频的 MP4；如果接口返回独立音频 URL，也下载到项目音频目录。
- 结果统一返回 `audio_source`、`native_audio_enabled`、`native_audio_path` 和音频是否存在。

### 任务与版本快照

视频任务和 `ShotVideoVersion` 保存：

- 实际模型、原生音频开关和音频来源；
- 对白计划版本及其来源镜头/对白 ID；
- 实际视频是否包含音频流；
- ASR 状态、识别文本、置信度和校正时间戳。

历史视频版本的音频策略固定，不受后续项目设置切换影响。

### 音频时间轴

- 原生音频镜头不创建重复的 TTS 台词轨道；原声作为 `native_video` 轨道参与混音。
- TTS 镜头继续使用现有逐句 `DialogueAudio` 轨道。
- `AudioAssets.source_audio_enabled` 根据实际项目轨道计算，不能由 TTS 任务无条件设为 `false`。
- BGM 作为独立轨道循环、裁切和淡化；对白或原声期间通过 sidechain 压低 BGM。
- 没有原声且没有 TTS 的镜头保持静音并显示警告。

## ASR 字幕校正

### 识别与匹配

1. 从成功的视频版本提取音频流。
2. 若本地 ASR 可用，输出带开始/结束时间的识别片段和置信度。
3. 按镜头顺序、说话人数量和对白计划进行匹配；保存原始剧本文本与识别文本的对应关系。
4. 使用文本相似度、片段顺序和置信度判断是否可信。

### 字幕策略

- ASR 可信：使用识别片段时间戳；默认字幕文本使用识别文本，保留剧本文本供追溯。
- ASR 低置信度或识别失败：使用剧本对白和已有音频计划时间；显示“未完成原声校正”。
- 识别出明显改词：任务详情显示差异，不覆盖原始剧本；用户可选择导出“实际原声字幕”或“剧本字幕”。内部试片默认使用实际原声字幕。
- ASR 过程失败不得删除视频、原声或已有字幕。

## 前端表现

- Seedance 镜头显示“原生对白”标签，其他模型显示“TTS 配音”。
- 音频时间轴显示原声轨、BGM 轨、音效轨和字幕校正状态。
- 任务详情显示原声是否存在、ASR 是否完成、识别置信度和改词警告。
- 设置页提供 ASR 开关、模型目录和“优先使用剧本字幕/实际原声字幕”选项；未安装 ASR 时说明回退行为。

## 错误与回退

- Seedance 不支持原生音频：按项目策略回退 TTS，并记录 `native_audio_unavailable`。
- 视频成功但没有音频流：保留视频，按策略生成 TTS 或标记无对白原声。
- 原生音频下载/提取失败：保留视频版本，BGM 可继续预览，正式合成显示警告。
- ASR 依赖或模型不可用：不阻断内部试片，使用剧本字幕时间轴。
- 音频轨道、字幕和视频时长无法对齐：阻止正式合成，但允许带警告导出预览。

## 兼容性

- 旧项目、旧可灵/快马/万相视频仍按原有 TTS 和视频原声兼容逻辑读取。
- 旧 `AudioAssets`、`DialogueAudio` 和 `tts_audio_path` 字段保留；新增字段提供默认值。
- 不改变既有视频模型的 API 请求形状，只有 Seedance 在能力开启时增加原生音频字段。

## 验证

- Mock Seedance 请求断言 `generate_audio=true`、对白块和原生音频元数据保存。
- 带音频/无音频 MP4 分别验证原声轨保留、缺失提示和 TTS 回退。
- Mock ASR 验证时间戳、文本相似度、改词警告和剧本字幕回退。
- FFmpeg 验证原声、BGM、音效和字幕同时存在时的时长、ducking 和响度。
- 验证旧项目和非 Seedance 模型回归不受影响。
