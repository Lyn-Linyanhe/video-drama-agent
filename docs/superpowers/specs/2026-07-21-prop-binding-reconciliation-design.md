# 道具绑定自动对账

## 目标

LLM 返回的视觉资产清单中，道具声明的 `shot_ids` 与镜头绑定的
`prop_ids` 偶尔不一致。这类可确定修复的数据不再导致剧本解析失败。

## 规则

1. 以每个镜头 `shot_bindings[].prop_ids` 为唯一事实来源，重建每个道具的
   `shot_ids`。
2. 只有被至少两个不同镜头引用，且通过既有剧情必要性校验的道具，才保留为
   可生成的关键道具资产。
3. 被零或单个镜头引用的道具从 `props` 及所有镜头绑定中移除。
4. 仍不能确定性修复的结构问题继续失败：镜头引用不存在的道具、重复或缺失
   镜头绑定、无效场景/地点绑定等。

## 验证

回归测试覆盖：

- 声明多镜头、实际绑定较少的道具会自动对账，不再触发不一致校验；
- 对账后仅绑定一个镜头的道具会被移除；
- 至少绑定两个镜头且具备剧情理由的道具会保留；
- 镜头引用不存在道具仍被校验拒绝。
