# Seedance API 适配设计

## 目标

将火山引擎 Ark Seedance 的视频任务请求、模型能力校验、参考图模式、首尾帧承接和供应商任务取消对齐官方 API，同时保持快乐小马、万相和 Mock 的现有配置与行为独立。

## 边界

- 不修改剧本生成、剧本解析、视觉提示词生成或已有分镜数据结构。
- 不删除 `output/` 中的历史视频、尾帧或项目资产。
- 不把 Seedance 的时长、分辨率和参考图规则套用到其他视频供应商。
- 旧项目保存的旧 Seedance 模型 ID 可以读取和播放历史版本，但不作为新任务默认选项。

## 设计

### 模型能力

Seedance 使用独立能力表，至少记录模型 ID、文生/图生能力、普通多参考图能力、首帧/首尾帧能力、参考图上限、支持分辨率、时长范围和默认音频行为。Seedance 未指定模型时默认 `doubao-seedance-2-0-fast-260128`。项目显式保存的 `model` 优先于默认值，API 设置保存不会覆盖项目策略。

### 参考图模式

任务快照在提交前确定一种模式：

- 无参考图：`text_to_video`。
- 连续镜头：将上一镜激活版本尾帧作为 `first_frame`；如果用户指定末帧，则使用 `first_frame + last_frame`。
- 非连续镜头：使用 `reference_image` 多参考模式，按模型上限截取。

官方互斥的模式不混发。被能力上限或模式互斥规则排除的图片不静默丢弃，快照记录 `accepted_references`、`dropped_references`、`reference_mode` 和原因，任务详情与工作台可以明确显示实际提交数量。

### 首尾帧与任务结果

Seedance 请求在连续性任务中发送 `return_last_frame=true`，成功响应中提取视频地址和官方末帧地址；末帧下载到当前项目的版本目录并写入视频版本。后续镜头只引用当前激活版本的尾帧，前镜切换版本后依赖状态继续由现有连续性逻辑标记过期。

### 音频与取消

项目统一后期配音，因此 Seedance 请求发送 `generate_audio=false`。提交成功后保存供应商任务 ID；本地任务取消时，Seedance 客户端调用官方 `DELETE /api/v3/contents/generations/tasks/{task_id}`，取消失败记录为诊断信息但不改变本地取消状态。其他供应商不调用该接口。

### 输入质量与错误

本地图片仍可使用官方接受的 Base64 Data URI，但压缩仅在必要时执行并尽量保留清晰度。连接测试和任务错误区分网络、鉴权、模型未开通、参数不支持和供应商任务失败。参考图安全策略拒绝时不再静默改成纯文本请求，必须在任务结果中标记降级或直接失败。

## 数据流

现有流程保持不变：剧本解析生成 `generation_prompts`，分镜编辑生成 `ShotPrompt`，视频提交时构建冻结快照。新增的 Seedance 适配只转换快照为官方 `content` 与任务字段，并将实际模式和参考图清单保存回快照；因此不会触发重新解析。

## 验证

- 默认 Seedance 模型和官方模型列表可由能力接口返回。
- 每个模型的时长、分辨率、参考图上限校验独立生效。
- 首帧、首尾帧、多参考图请求的 `role`、互斥关系和数量正确。
- 连续任务携带 `return_last_frame`，结果尾帧可保存并供下一镜引用。
- 取消任务调用官方 DELETE，其他供应商测试不受影响。
- 现有快乐小马、万相、Mock、剧本解析、分镜提示词和资产路径回归测试继续通过。
