# 统一资产库与道具链路设计

## 目标

将现有独立的角色页和场景页统一为“资产库”页面，在该页面内通过角色、场景、道具三个页签管理视觉素材。新增关键道具的剧本提取、中文提示词、六视图图片生成、人工编辑和分镜视频参考图绑定能力。

本次只处理资产库和道具链路，不修改已规划的音频台词与字幕修复。

## 已有基础与约束

项目已具备：

1. 角色资产：每个出镜角色的正面半身、正面全身、左侧面、背面全身四张独立图片；支持提示词编辑、重生成、上传和历史版本。
2. 场景资产：按可复用地点去重的无人物场景图；支持提示词编辑、重生成、上传和历史版本。
3. 镜头生产状态：为每个镜头保存可增删、排序的参考图，并将当前选择传给视频生成模型。
4. 视觉资产清单：`VisualAssetManifest` 已将角色、地点和镜头绑定从时间分镜中分离。

兼容原则：不迁移、不删除已有角色、场景、图片或视频；旧项目没有道具数据时按空道具列表读取，角色和场景继续按现有逻辑可用。

## 道具提取

在视觉资产清单新增 `PropAsset`，字段包含：稳定 `prop_id`、名称、生产用外观描述、材质与结构特征、关联镜头 ID、是否被角色手持、别名。`ShotVisualBinding` 新增 `prop_ids`。

LLM 只提取以下关键道具：

1. 需要在多个镜头中保持外观一致的物件。
2. 被角色手持、操作、展示或交接的物件。
3. 触发、承载或推动剧情的物件。

普通家具、环境陈设、一次性杂物、仅作为背景的物体和未真正出现在画面中的提及物不创建独立道具资产，也不进入视频参考图。资产清单校验会确认每个道具至少关联一个镜头，并且每个镜头只能绑定清单中存在的道具 ID。

## 道具提示词与图片

每个道具默认生成一张横向六视图参考图，而非六张独立图片。提示词必须为中文，固定遵循下列约束：

1. 高质量写实产品影棚摄影，纯白背景，横向 2 行 3 列干净网格。
2. 六个标准正交视图：绝对正前、绝对正后、绝对左、绝对右、绝对正上、绝对正下。
3. 同一件道具跨视图保持材质、颜色、比例和结构一致；最小化透视畸变，保持画面端正、居中、完整。
4. 禁止人物、手、脚、人脸、场景、建筑、自然景观、其他道具、文字、水印、Logo、UI 和剧情事件。
5. 最后附加由视觉设计继承的影视写实风格描述，但不允许风格要求破坏产品参考图的清晰度、白底或正交视角。

道具图保存至 `output/<project_id>/assets/props/<prop_id>/`。每次重生成或上传均保留历史版本；当前活动版本是视频参考图和资产库预览的唯一来源。

## 资产库页面

侧栏、步骤栏及页面入口改为“资产库”。原角色和场景入口保留兼容重定向，分别定位到资产库的角色和场景页签。

资产库页面包含三个固定页签：

1. 角色：沿用四视图卡片和既有操作。
2. 场景：沿用按可复用地点去重的场景卡片和既有操作。
3. 道具：显示六视图卡片、道具名称、关联镜头和是否手持；支持查看与编辑提示词、生成、上传、历史版本和切换活动版本。

三类卡片使用一致的交互入口，但各自保留合适的图片规格与提示词模板。资产库不嵌套页面卡片，也不重复展示生产工作台的镜头引用编辑。

## 分镜制作和视频生成

分镜制作工作台左侧资产栏新增“道具参考”分组。默认参考图按镜头绑定自动填充：地点图、实际出镜角色图和关键道具图。用户仍可以在工作台手动增删、排序任意三类参考图，保存后严格按人工选择生成。

视频 Prompt 注入当前镜头已绑定道具的名称、用途和外观连续性约束；参考图路径以用户保存的顺序传给视频生成模型。没有镜头绑定的道具不会自动传入，也不会仅因其存在于资产库而影响视频生成。

“一键准备参考图并生成视频”会在缺失时生成本项目所需的角色、场景和道具参考图，并只绑定该镜头实际需要的资产。

## 接口与持久化

新增道具图片模型和 `PropImageAssets`，并纳入 `DramaState` 的序列化、项目恢复和资产扫描。扩展现有图片资产接口，使 `asset_type=prop` 支持：获取详情、生成、重生成、上传、历史版本和切换活动版本。

新增项目级道具重新提取和批量生成接口。生产数据接口的资产目录包含 `characters`、`scenes`、`props` 三类；参考 ID 使用稳定、可解析的 `prop|<prop_id>|standard_views` 格式。视频生成 Agent 的参考图构建逻辑读取 `ShotVisualBinding.prop_ids`。

所有状态以服务端项目状态为事实来源，操作后立即保存。旧项目缺少 `props`、`prop_images` 或 `prop_ids` 时自动填充空值并继续运行。

## 验收与测试

1. 解析剧本时仅提取关键道具；家具、背景杂物、纯提及对象不会生成道具资产。
2. 录音机、钥匙等重复或剧情关键道具拥有稳定 ID、关联镜头和中文六视图提示词。
3. 道具图片满足横向 2x3 六视图、纯白背景、无人无文字约束；重生成与上传均可回看和切换历史版本。
4. 资产库在角色、场景、道具三个页签中正确呈现旧项目与新项目资产，旧角色/场景入口仍可定位到对应页签。
5. 镜头默认引用仅包含其绑定的角色、场景、道具；手动移除道具后视频请求不再注入该图。
6. 视频 Prompt 与参考图顺序包含绑定道具；未绑定道具不影响视频生成。
7. 旧项目无道具相关字段时可加载、生成原角色/场景与视频，且不删除任何已有资产。
